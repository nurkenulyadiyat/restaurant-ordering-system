This ZIP is **a source contribution package**, not a standalone app. The final submission must be the integrated project, not three separate applications. The source files retain their correct relative Java package paths.

## Integration steps

1. Extract this ZIP in a workspace.
2. Copy its `restaurant-ordering-system/src` contents into the shared project's `src` folder, preserving paths.
3. Merge the three teammates' module folders, and use the shared `Main.java`, scripts and tests in `Restaurant_Ordering_System_COMPLETE.zip`.
4. Run `test.bat` on Windows or `sh test.sh` on Linux/macOS. Use `run.bat --demo` / `sh run.sh --demo` for the end-to-end defense demonstration.
